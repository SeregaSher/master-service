# Монетизация

## Клиенты

- бесплатный поиск и база знаний;
- маленький сервисный сбор за защищенную сделку;
- платная срочная заявка;
- платная проверка сметы платформой;
- гарантийный пакет на работу через платформу.

## Мастера

- бесплатный профиль;
- комиссия только с успешной сделки;
- Pro-подписка: CRM, склад, клиенты, гарантия, шаблоны смет;
- платный доступ к профессиональной базе знаний;
- платное продвижение в категории/городе;
- платные проверенные бейджи;
- платные срочные лиды, но только валидные.

## Магазины запчастей

- витрина магазина;
- комиссия с продажи;
- платное размещение в рекомендациях деталей;
- интеграция остатков;
- B2B-пакет для поставщиков.

## За что люди захотят платить

Не за доступ к сайту. Платить будут за снижение риска:

- клиент не хочет быть обманутым;
- мастер не хочет ехать бесплатно;
- магазин хочет продавать нужную деталь в нужный момент;
- поддержка и арбитраж снимают страх сделки.
