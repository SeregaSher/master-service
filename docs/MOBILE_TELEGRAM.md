# Мобильные приложения или Telegram

## Самый быстрый путь

Сначала лучше сделать:

```text
PWA сайт + Telegram Mini App
```

Почему:

- не надо ждать App Store / Google Play;
- не надо заставлять клиента ставить приложение;
- Telegram уже есть у многих пользователей;
- можно использовать тот же frontend;
- бот может присылать уведомления, брони, споры, напоминания;
- мастер может быстро нажать `Я на месте`.

## Что такое Telegram Mini App

Это web-интерфейс, который открывается внутри Telegram. По сути, тот же сайт, но встроенный в бота. Можно сделать одну UI-систему:

```text
web app
   |
   +-- обычный сайт app.wpservice.co.il
   +-- Telegram Mini App из бота
   +-- PWA на телефоне
```

## Что оставить в Telegram-боте

- уведомления о новой заявке;
- подтверждение брони;
- напоминание мастеру;
- кнопка открытия Mini App;
- быстрые статусы: `принять`, `в пути`, `я на месте`;
- поддержка и арбитраж;
- уведомления клиенту о приезде мастера.

## Когда делать полноценные Android/iOS

Когда уже есть:

- стабильный поток заявок;
- мастера реально пользуются CRM;
- нужна работа с камерой, GPS, push и offline;
- есть бюджет на поддержку приложений.

Тогда можно взять один из путей:

- React Native, если frontend будет React/Next.js;
- Flutter, если нужна единая мобильная кодовая база;
- нативные приложения, если появятся сложные требования.

## Практичный план

1. MVP web/PWA.
2. Telegram bot + Telegram Mini App.
3. Cloudflare + backend.
4. Только потом полноценные приложения.

Так ты не тратишь месяцы на магазины приложений до проверки бизнеса.
